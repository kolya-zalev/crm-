# Team Chat (SSE + TanStack Query) — План

**Подход:** Approach A — SSE + `setQueryData` (direct mutation)  
**Репозитории:** `crm-server` (backend) + `crm-` (frontend)  
**Гайд:** https://ollioddi.dev/blog/tanstack-sse-guide

---

## Цель

Общий чат команды: история сообщений в PostgreSQL, новые сообщения приходят **мгновенно** через SSE, UI обновляется через TanStack Query `setQueryData`.

## MVP — что входит

- [x] Одна комната для всей команды
- [x] GET история (50 сообщений)
- [x] POST отправка
- [x] SSE real-time
- [x] Страница `/chat` + пункт в sidebar

## MVP — что НЕ входит

- Edit / delete сообщений
- Typing indicator, read receipts
- Lead-чаты, личные DM
- Optimistic updates
- WebSockets

---

## Архитектура

```
[Загрузка страницы]
  useQuery → GET /api/chat/messages → история в кеш

[Real-time]
  EventSource → GET /sse/chat-events?accessToken=...
  onmessage → setQueryData (добавить сообщение в кеш)

[Отправка]
  POST /api/chat/messages → сохранить в БД → broadcast всем SSE-клиентам
```

**Важно:** POST **не** обновляет кеш на frontend. Обновление только через SSE — один путь, проще отладка.

## Фаза 4 — Backend: SSE endpoint

### Task 5: `GET /sse/chat-events`

**Зачем:** Открытый HTTP-поток. Сервер пушит события, браузер слушает через `EventSource`.

**Файл:** `crm-server/src/chat/chat-sse.controller.ts`

**Логика:**
1. Взять `accessToken` из query
2. `validateAccessToken(token)`
3. Создать `ReadableStream`
4. `registerSSEConnection` в channel `chat`
5. Отправить welcome event `connected`
6. На `req.close` → `unregisterSSEConnection`

**Headers ответа:**
- `Content-Type: text/event-stream`
- `Cache-Control: no-cache`
- `Connection: keep-alive`

**Проверка:**
```bash
curl -N "http://localhost:3001/sse/chat-events?accessToken=TOKEN"
```
Поток открыт, приходит event `connected`.

### Task 10: `useChatSSE` ← главный hook

**Зачем:** Мост SSE → TanStack Query. Сердце Approach A.

**Файл:** `src/features/chat/hooks/useChatSSE.ts`

**Логика:**
1. `useSession()` → `accessToken`
2. `useEffect` → `new EventSource(url + ?accessToken=...)`
3. `onmessage` → parse JSON → `setQueryData(chatQueryKey, appendChatMessage)`
4. `return () => eventSource.close()`
5. Вернуть `{ isConnected }`

5. Пишешь **«готово»** → следующий Task
